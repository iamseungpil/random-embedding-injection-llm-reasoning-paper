\begin{abstract}
학습되지 않은 무작위 임베딩을 LLM 입력에 끼워 넣는 것만으로도 모델의 추론 행동은 비자명하게 바뀐다. 최근의 \textit{soft prompt} 계열 방법은 가상 토큰 임베딩을 최적화해 수학 추론 성능을 끌어올렸지만, 그 이득이 \emph{학습}에서 오는지 \emph{주입} 자체에서 오는지는 분리되어 있지 않다. 본 논문은 학습 단계를 완전히 제거한 Random Soft Prompt(RSP)를 분석한다. RSP는 사전학습 임베딩 행렬의 항별 평균과 분산에 맞춘 등방 가우시안에서 샘플한 연속 벡터를 그대로 주입한 것이다. 분석은 두 부분으로 이루어진다. 한 rollout 안에서는 exact attention decomposition이 RSP가 생성 초반의 next-token 결정을 흔들 수 있지만 자기회귀 캐시가 자라면 그 영향이 약해짐을 보인다. rollout 사이에서는 등방 prompt가 고정 분산 예산 아래 방향 무관이며 모든 비공집합 열린집합에 양의 확률을 부여하므로, 독립 재추첨이 초반 branch를 다시 열 수 있고 별도의 과제 측 성공 가정 아래 Pass@$N$ 증가로 이어진다. 실험은 이 구조와 맞물린다. 학습 없는 RSP는 최적화된 soft prompt와 경쟁적인 성능을 보이고, 초반 토큰 분포는 더 다양해진 뒤 후반에 안정화되며, 같은 RSP를 모든 sample에 공유하면 Pass@$N$ 이득이 사라진다. 마지막으로 이 다양성이 GRPO 학습에 갖는 함의를 논의한다.
\end{abstract}
