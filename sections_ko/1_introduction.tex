\section{서론}
\label{sec:introduction}

본 연구는 soft prompt를 다루는 과정에서, \emph{학습되지 않은} 무작위 임베딩만으로도 일부 설정에서 정확도를 회복하고 초반 디코딩 분포를 바꿀 수 있다는 사실을 발견한 것에서 출발했다. LLM이 커지면서 전체 미세조정 비용이 커졌고, 소수 파라미터만으로 적응시키는 parameter-efficient 방법이 주목받고 있다 \citep{hu2022lora, houlsby2019adapter}. 그중 \textit{soft prompt}는 학습 가능한 연속 임베딩을 입력에 삽입해 attention으로 모델 행동을 조정하며 \citep{li2021prefix, lester2021power}, 수학 추론 강화에도 활발히 쓰인다 \citep{kang2025model, xu2025softcot, ye2025thinking, hao2024training, zhang2025memgen}. 이들은 어휘 바깥 연속 임베딩을 주입하고 \emph{최적화}한다는 공통 구조를 가지며, 기존 연구는 그 이득을 \emph{학습된 값}이 만든 결과로 해석해 왔다 --- 주입 자체의 구조적 효과는 충분히 다뤄지지 않았다.

\emph{학습된 내용}과 \emph{주입 행위}를 분리하기 위해 random soft prompt(RSP)를 control로 도입했다 --- 임베딩 행렬의 평균·분산에 맞춘 등방 가우시안에서 추첨한 연속 벡터로, 어떤 학습도 거치지 않는다. 이 control은 예상과 달리 neutral하지 않다. chat 형식으로 학습되지 않은 base model에 chat template을 적용하면 형식 불일치로 추론이 크게 떨어지는데, RSP를 덧붙이면 Qwen2.5-Math-1.5B에서 $+29$ pp까지 회복된다. 단순 노이즈라면 정확도는 더 나빠져야 한다. 학습된 의미와 무관하게 \emph{주입} 자체가 모델 행동을 비자명하게 바꾼다는 뜻이다. 기존 연구는 최종 정확도에만 집중해 주입과 최적화의 효과를 분리하지 못했다.

본 연구는 학습 없이 주입되는 RSP가 LLM 추론에 미치는 효과를 분석한다. rollout마다 \emph{독립}된 RSP를 추첨하면 단발의 RSP 주입이 hidden state를 여러 trajectory로 \textit{branching}시키고, 디코딩이 깊어질수록 \textit{안정화}되어 목표 응답으로 수렴한다. 실험적으로 RSP는 학습된 의미가 없음에도 LTPO·TTSV·SoftCoT 등 최적화된 방법과 동일한 초반 entropy 시그니처를 공유하고, sample마다 \emph{독립} RSP를 쓸 때만 Pass@$N$이 누적되며, 같은 입력 단 다양성이 DAPO \citep{yu2025dapo} 학습과도 결합 가능하다. 본 연구의 기여는 세 가지다. (i) 학습되지 않은 RSP를 \emph{non-neutral control}로 두어 \emph{학습된 내용}과 \emph{주입 행위}를 분리하고, 일부 설정에서 RSP가 최적화된 soft prompt와 비교 가능한 범위에 도달함을 보이며 trained 방법이 만들어 내는 효과의 일정 부분이 \emph{주입 구조의 부산물}일 수 있음을 시사한다. (ii) attention-mediated branch opening, 등방적 directional coverage, KV-cache attenuation으로 그 메커니즘을 이론적·실험적으로 정리한다. (iii) 독립 RSP 재추첨이 rollout 다양성 학습(DAPO)과도 결합 가능함을 확장 실험으로 보인다.

본 연구는 학습 없이 주입되는 Random Soft Prompt(RSP)가 LLM의 추론에 가지는 효과를 분석한다. RSP는 사전학습 임베딩의 항별 평균·분산에 맞춘 등방 가우시안에서 추첨한 연속 벡터로, rollout마다 \emph{독립}된 섭동을 공급해 더 넓은 탐색을 가능케 한다. RSP는 초반 entropy를 높이고 temperature와 결합해 Pass@$N$ 다양성을 확장한다.  \emph{학습 없는 무작위 주입}만으로 latent reasoning이 작동한다는 사실은 기존 soft prompt 효과의 일정 부분이 학습된 의미가 아니라 \emph{주입 자체}에서 올 수 있음을 시사한다. 이 지점에서 본 연구는 RSP의 탐색 성능 향상 효과를 GRPO \citep{shao2024deepseekmath} 학습으로 확장한다. 이 지점에서 본 연구는 세 가지 기여를 가진다. 먼저, 

본 논문의 기여는 다음과 같다.
\begin{itemize}
  \item 트랜스포머 수준 메커니즘 제시. RSP의 기여는 cache-growth 상한 envelope을 갖는 단일 스칼라 어텐션 질량으로 통제되고, 국소 affine surrogate 분석에서 \emph{고정 섭동이 아닌 등방 재추첨}이 temperature가 만들 수 없는 top-$K$ 진입 영역에 도달할 수 있음을 보인다.
  \item 실증 분석. RSP는 초반 토큰 entropy를 높이고 temperature와 결합 시 더 다양한 추론 궤적을 만들며, 같은 RSP를 sample 간 공유하면 누적 이득이 사라진다.
  \item GRPO 학습 함의 논의. RSP는 순위를 \emph{바꾸는} 섭동, temperature는 \emph{보존}하는 섭동이므로 둘은 직교하는 탐색 이득을 제공한다.
\end{itemize}
