\subsection{Random Soft Prompt의 정의와 설정}\label{sec:rsp_definition}
% ================================================================

사전학습된 LLM의 토큰 임베딩 행렬을 $\mathbf{W}_E \in \mathbb{R}^{V \times d}$라 하자. 여기서 $V$는 어휘 크기이고 $d$는 은닉 차원이다. 우리는 RSP를 $L$개의 연속 벡터 시퀀스 $\mathbf{H} = [h_1, \dots, h_L] \in \mathbb{R}^{L \times d}$로 정의하며, 각 벡터는 다음 분포에서 독립적으로 샘플링된다.
\begin{equation}
  h_j \sim \mathcal{N}(\mu_E,\; \sigma_E^2 \mathbf{I}), \quad j = 1, \dots, L,
\end{equation}
여기서 $\mu_E = \frac{1}{Vd}\sum_{i,k} [\mathbf{W}_E]_{i,k}$, $\sigma_E = \mathrm{std}(\mathbf{W}_E)$이다. 원래 입력의 임베딩 시퀀스를 $\mathbf{X} = [x_1, \dots, x_T] \in \mathbb{R}^{T \times d}$라 하면, RSP가 주입된 입력 $\tilde{\mathbf{X}}$는 원래 프롬프트 텍스트는 바꾸지 않은 채 세 위치 중 하나에서 $\mathbf{H}$를 연결해 만든다: \textit{prefix} ($[\mathbf{H}; \mathbf{X}]$), \textit{infix} ($\mathbf{H}$가 $\mathbf{X}$ 내부에 삽입됨), \textit{suffix} ($[\mathbf{X}; \mathbf{H}]$). 이는 선행 연구의 주입 전략을 따른다 \citep{kang2025model, xu2025softcot, ye2025thinking, zhang2025memgen}. 각 배치마다 새로운 $\mathbf{H}$를 샘플링함으로써, 결과가 특정 무작위 임베딩 실현값 하나에 의존하지 않도록 했다.

평가는 세 가지 수학 추론 벤치마크, MATH-500 \citep{lightman2024lets}, GSM8K \citep{cobbe2021training}, AIME24에서 수행한다. 모델은 LLaMA-3.1-8B-Instruct \citep{grattafiori2024llama}와 Qwen2.5-Math 계열 \citep{yang2024qwen25math}을 사용하며, instruct model, base model, 그리고 chat template이 맞지 않는 base model까지 포함해 총 일곱 설정을 비교한다. 모든 실험은 sampling 자체의 무작위성과 RSP 효과를 분리하기 위해 greedy decoding을 사용한다. 평가는 fallback 기반의 answer extraction pipeline으로 최종 답만 채점한다. 전체 실험 설정은 Appendix~\ref{app:setup}에 정리했다.

\subsection{RSP는 출력 분포를 어떻게 바꾸는가?}\label{sec:entropy}
% ================================================================

결과는 RSP가 생성 초반 출력 분포를 분명히 바꾼다는 점을 보여준다. 세 주입 위치 모두에서 entropy는 증가하고, top-1 probability는 감소하며, varentropy는 증가한다. 이는 분포가 평평해지고, 단일 우세 토큰에 대한 확신은 약해지며, 다봉형 분포가 더 자주 나타남을 뜻한다 \citep{ahmed2026logitscope}. 높은 entropy 구간은 추론 궤적이 갈라지는 핵심 분기점으로 알려져 있으므로 \citep{wang2025beyond}, 이 변화는 여러 추론 경로가 공존할 수 있는 상태로 모델을 밀어 넣는다. 중요한 점은 변화가 생성 초반에 국한된다는 것이다. 생성 중반과 후반에서는 세 지표 모두 baseline 수준으로 다시 수렴한다.

기존 soft prompt 방법들은 서로 다른 목적 함수로 학습되었음에도, 생성 초반 entropy를 높인다는 공통 패턴을 보인다. 특히 reasoning trajectory의 평균 entropy를 줄이는 보상으로 soft prompt를 최적화하는 TTSV조차 초반 entropy는 baseline과 비슷하거나 더 높은 수준을 보인다. 이는 생성 초반 entropy 상승이 특정 최적화 목적 때문이 아니라, 사전학습되지 않은 연속 임베딩을 주입하는 행위 자체에 가까운 효과일 수 있음을 시사한다.

\subsection{RSP는 실제로 추론 궤적의 다양성을 만드는가?}\label{sec:diversity}
% ================================================================

Section~\ref{sec:entropy}는 RSP가 생성 초반 출력 분포를 바꾼다는 사실을 보였다. 이제 이 변화가 실제 추론 다양성으로 이어지는지를 세 수준에서 살펴본다. 분석 수준은 토큰 순위, 궤적의 의미적 내용, 과제 수준 결과다. 세 분석 모두 Qwen2.5-Math-1.5B-Instruct, MATH-500, suffix 주입, $L=10$ 설정을 공유한다.

\paragraph{토큰 수준: temperature만으로는 얻을 수 없는 분포 이동.}

자기회귀 생성에서 baseline과 RSP의 궤적 차이는 결국 첫 토큰에서 시작될 수밖에 없다. 따라서 baseline $\tau{=}1.0$을 기준으로, 단순한 flattening이 만들 수 있는 상한선인 baseline $\tau{=}2.0$과 RSP $\tau{=}1.0$을 비교한다. 비교 지표는 세 가지다. Spearman rank correlation $\rho$는 순위 재배치를, baseline의 top-10 밖에 놓이는 확률 질량은 지지 집합 확장을, Jensen--Shannon divergence는 분포 변화의 전체 크기를 측정한다(정의는 Appendix~\ref{app:token_metrics}).

Table~\ref{tab:rsp_vs_temp}는 RSP가 temperature scaling과는 질적으로 다른 변화를 만든다는 점을 보여준다. $\tau{=}2.0$까지 올려도 baseline top-10 밖으로 이동하는 확률 질량은 5.15\%에 그치지만, RSP $\tau{=}1.0$은 27.64\%에 도달한다. Spearman 상관은 더 직접적이다. Temperature scaling은 $p_i^{(\tau)} \propto p_i^{1/\tau}$라는 단조 변환이므로 어떤 $\tau > 0$에서도 토큰 순위를 보존하며, baseline 대비 $\rho$는 정확히 1이다. 반면 RSP는 토큰 분포의 순위 자체를 뒤섞어 $\rho$를 0.651까지 낮춘다. 이 변화는 temperature만으로는 만들 수 없다. JS divergence 0.231은 이 분포 변화의 전체 크기를 요약한다. 즉, RSP는 같은 순위를 단순히 평평하게 만드는 것이 아니라 분포 구조 자체를 다시 짠다.

\end{figure}

Figure~\ref{fig:semantic_diversity}(a)는 이 차이를 시각적으로 보여준다. RSP 샘플(파랑)은 baseline 샘플(빨강)이 차지하는 영역을 포함하면서, baseline이 도달하지 못한 별도 클러스터까지 확장된다. 그리고 새로 열린 영역에도 정답 궤적이 포함되어 있어, RSP의 탐색이 단지 오답 변형으로만 흩어지는 것은 아님을 알 수 있다. Figure~\ref{fig:semantic_diversity}(b), (c)는 이러한 패턴이 64개 문제 전반에 걸쳐 반복됨을 보여준다. 대부분의 문제에서 RSP는 더 많은 클러스터와 더 큰 pairwise cosine distance를 만든다. 큰 inter-cluster 증가와 거의 변하지 않는 intra-cluster 거리는 토큰 수준의 결과와도 맞닿아 있다. RSP는 각 클러스터 내부의 진행은 흐트러뜨리지 않으면서, 궤적이 진입하는 전략 클러스터 자체를 바꾼다. 문제별 추가 t-SNE 그림은 Appendix~\ref{app:semantic}의 Figure~\ref{fig:app_tsne_grid}에 제시한다.

\paragraph{결과 수준: Pass@$n$ 스케일링.}
마지막으로 토큰 수준과 궤적 수준의 다양성이 실제 과제 성과의 다양성으로 이어지는지 본다. 지표는 Pass@$n$이며, 이는 $n$개의 샘플 중 적어도 하나가 정답일 확률이다. MATH-500과 AIME24에서 문제당 $n=16$개의 샘플을 생성하고, 다음 네 조건을 비교한다. \textit{(i)~Baseline, $\tau\!=\!1.0$}: temperature sampling만 사용. \textit{(ii)~RSP (fixed seed), $\tau\!=\!1.0$}: 하나의 RSP를 모든 샘플이 공유. \textit{(iii)~RSP (indep.\ seed), greedy}: 샘플마다 다른 RSP를 쓰되 temperature는 사용하지 않음. \textit{(iv)~RSP (indep.\ seed), $\tau\!=\!1.0$}: 샘플마다 다른 RSP와 temperature sampling을 함께 사용.

\begin{figure}[ht]
  \centering
  \includegraphics[width=\textwidth]{img/diversity/pass_at_n_combined.pdf}
  \caption{Qwen2.5-Math-1.5B-Instruct에서의 Pass@$n$ 스케일링. 좌측은 MATH-500, 우측은 AIME24이며, 문제당 $n=16$개의 샘플을 사용했다. Baseline은 temperature sampling만, fixed seed는 고정된 하나의 RSP와 temperature를 함께 쓴 경우, indep.\ seed는 샘플마다 다른 RSP를 쓰는 경우다.}
  \label{fig:pass_at_n}
\end{figure}

조건 \textit{(iv)}가 두 벤치마크 모두에서 가장 높은 Pass@$n$를 달성한다. $n=16$에서 MATH-500은 92.80\%, AIME24는 36.67\%까지 올라간다. 반면 \textit{(ii)}는 baseline 대비 개선이 거의 없어, 다양성 이득의 핵심이 하나의 고정 섭동이 아니라 샘플마다 다른 무작위 임베딩이라는 점을 보여준다. Pass@1은 MATH-500에서 baseline과 비슷한 수준을 유지하고, 더 어려운 AIME24에서는 \textit{(iv)}가 baseline보다 더 높다. 즉, 독립적인 RSP와 temperature sampling의 결합은 단일 샘플 정확도를 해치지 않으면서 더 다양한 추론 궤적을 생성한다.

\paragraph{세 수준의 종합.}
세 분석은 하나의 일관된 그림으로 수렴한다. 토큰 수준에서는 RSP가 첫 토큰에 집중된 지지 집합 확장을 만들고, 그 효과는 뒤 토큰으로 갈수록 단조롭게 약해진다. 궤적 수준에서는 이 국소적 섭동이 서로 다른 추론 전략을 열어 큰 inter-cluster 분리를 만들지만, 각 전략 내부의 국소적 일관성은 유지된다. 결과 수준에서는 그렇게 생성된 궤적들이 더 많은 정답 해를 덮으면서도 단일 샘플 정확도를 잃지 않는다.
