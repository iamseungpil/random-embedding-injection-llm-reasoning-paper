\section{Background}\label{sec:background}

% ----------------------------------------------------------------
\subsection{Soft Prompt Methods for LLM Reasoning}\label{sec:rw_soft_prompt}
% ----------------------------------------------------------------

Existing \textit{soft prompt} methods all share a common structure: they inject out-of-vocabulary continuous embeddings and \emph{optimize} them under task-specific objectives. Because evaluation is anchored to end-task accuracy, the contributions of ``injection itself'' and ``optimization'' are not separated, and how plain embedding injection reshapes model behavior remains an open question. As parameter-efficient alternatives to full fine-tuning, Prefix-Tuning \citep{li2021prefix}, Prompt Tuning \citep{lester2021power}, and P-tuning \citep{liu2021gpt} reached near-fine-tuning performance using learnable continuous vectors, after which LLM-reasoning-specific variants quickly followed. TTSV \citep{kang2025model} optimizes prefix embeddings at test time via entropy minimization; SoftCoT \citep{xu2025softcot} replaces explicit chain-of-thought tokens with soft tokens generated by an assistant model; LTPO \citep{ye2025thinking} optimizes per-instance latent thought embeddings with confidence-based rewards; COCONUT \citep{hao2024training} feeds the model's own hidden states back as input embeddings; MemGen \citep{zhang2025memgen} uses embedding vectors as experience memory; and Pause tokens \citep{goyal2024think} insert learnable tokens to provide additional computation steps.

\subsection{Noise Injection in Neural Networks}\label{sec:rw_perturbation}
% ----------------------------------------------------------------

Neural networks have incorporated noise at several stages. During training, dropout \citep{srivastava2014dropout} randomly deactivates hidden units, and NEFTune \citep{jain2024neftune} adds noise to embeddings during instruction fine-tuning to improve instruction following. At inference time, randomized smoothing \citep{cohen2019certified} injects Gaussian noise into inputs to obtain certified robustness, and SmoothLLM \citep{robey2023smoothllm} perturbs prompts at the character level to defend against jailbreaking. In RL, NoisyNet \citep{fortunato2018noisy} adds learnable noise to network weights to aid exploration.

RSP differs from these in three respects. \textbf{(1)} It operates without any training, purely at inference, and does not modify model parameters (unlike dropout, NEFTune, and NoisyNet). \textbf{(2)} It preserves the original input and appends the embedding within a single forward pass, so it does not require the ``multiple noisy passes plus aggregation'' that robustness methods need. \textbf{(3)} It uses vectors drawn directly from the pretrained embedding statistics, with no learned parameters at all (NoisyNet, by contrast, learns its noise parameters). The goal of RSP is not output stability but \emph{exploration}, and this paper analyzes how that difference operates at the attention level.
